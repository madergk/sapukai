A comprehensive, accessible React component library built with **Tailwind CSS v4**, **TypeScript**, and **Radix UI** primitives. Extracted from the [Catalyst UI Figma](https://www.figma.com/design/rxkEYwOrbpifrqowduvVHM/Catalyst-UI) design system.

---

## Quick Start

### Installation

```bash
npm install
```

### Usage

```tsx
import { Button, Badge, Avatar, Input } from '@/components'

function App() {
  return (
    <div>
      <Button>Click me</Button>
      <Badge color="green">Active</Badge>
      <Avatar initials="JD" />
      <Input label="Email" placeholder="you@example.com" />
    </div>
  )
}
```

Basic building blocks: **Button**, **Badge**, **Avatar**, **Divider**, **Heading**, **Text**

### Feedback

User feedback: **Dialog**

### Navigation

Navigation patterns: **Dropdown**, **Pagination**, **Navbar**, **Sidebar**
