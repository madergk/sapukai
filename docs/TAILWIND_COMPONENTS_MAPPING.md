# Tailwind Labs Component Mapping

This document maps existing components to Tailwind Labs sources and patterns.

## Primitives

- `Button` → Tailwind CSS button patterns
- `Text` → Tailwind typography utilities
- `Heading` → Tailwind typography utilities
- `Divider` → Tailwind border utilities
- `Badge` → Tailwind badge patterns
- `Avatar` → Tailwind avatar patterns

## Forms

- `Input` → Tailwind form input patterns
- `TextArea` → Tailwind textarea patterns
- `Checkbox` → Headless UI `Checkbox` pattern
- `Radio` → Headless UI `RadioGroup` pattern
- `Switch` → Headless UI `Switch` component
- `Select` → Headless UI `Listbox` component
- `Listbox` → Headless UI `Listbox` component

## Feedback

- `Dialog` → Headless UI `Dialog` component

## Data

- `Table` → Tailwind table patterns
- `DescriptionList` → Tailwind description list patterns

## Navigation

- `Dropdown` → Headless UI `Menu` component
- `Pagination` → Tailwind pagination patterns
- `Navbar` → Tailwind navbar patterns
- `Sidebar` → Tailwind sidebar patterns
